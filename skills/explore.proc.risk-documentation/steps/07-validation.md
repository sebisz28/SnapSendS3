# Step 7: Validation

## Objective

Run a completeness check on the risk register.

## Entry Criteria

- [ ] Step 6 (Write Document) complete
- [ ] Document exists at `explore/explore-[slug]/risks.md`

## Actions

### 7.1 Run Completeness Check

Verify all required elements:

- [ ] All risks coded and numbered (T1, B1, O1, C1, etc.)
- [ ] Impact and likelihood scored for each risk
- [ ] Risk score calculated correctly (Impact × Likelihood)
- [ ] Mitigation strategies defined for all open risks
- [ ] Contingency plans documented
- [ ] Owners assigned to all open risks
- [ ] Accepted risks have rationale and approver
- [ ] Related ADRs/assumptions linked
- [ ] Risk dependencies mapped
- [ ] Mitigation timeline created

### 7.2 Present Validation Results

```
Risk Documentation Complete

File: explore/explore-[slug]/risks.md
Total Risks: [N]
  - Critical: [N]
  - High Priority: [N]
  - Medium Priority: [N]
  - Low Priority: [N]
Accepted Risks: [N]
Mitigation Strategies: [N] defined

Validation: [N] of [N] checks passed ✓

Ready for PRD Generation.
```

## Exit Criteria

- [ ] All completeness checks pass
- [ ] Validation results presented to human
- [ ] Document ready for downstream consumption
