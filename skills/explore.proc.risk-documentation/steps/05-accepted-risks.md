# Step 5: Document Accepted Risks

## Objective

For any risks marked as "Accepted" by the human, document the rationale, approver, and monitoring plan.

## Entry Criteria

- [ ] Step 4 (Present Validation) complete with human approval

## Actions

### 5.1 Document Each Accepted Risk

For any risks the human chose to accept:

```
Accepted Risk: [ID]

Risk: [Description]
Why Accepted: [Business rationale for accepting this risk]
Accepted By: [Decision maker name/role]
Date Accepted: [Date]
Monitoring Plan: [How we'll watch for this risk materializing]
Escalation Trigger: [What would cause us to revisit this decision]
```

### 5.2 Skip if No Accepted Risks

If all risks have mitigation strategies and none are accepted, proceed to Step 6.

## Exit Criteria

- [ ] All accepted risks have documented rationale
- [ ] Approver name/role recorded
- [ ] Monitoring plan and escalation trigger defined per accepted risk
