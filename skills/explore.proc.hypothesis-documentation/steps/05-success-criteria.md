# Step 5: Define Success Criteria

## Objective

Make "We will know this is true when" measurable with specific metrics, baselines, and targets.

## Entry Criteria

- [ ] Step 4 (Identify Assumptions) complete

## Actions

### 5.1 Define Metrics

```
Success Criteria

| Metric | Baseline | Target | Measurement Method | Timeline |
|--------|----------|--------|-------------------|----------|
| [Metric 1] | [Current state] | [Desired state] | [How to measure] | [When] |
| [Metric 2] | [Current state] | [Desired state] | [How to measure] | [When] |
| [Metric 3] | [Current state] | [Desired state] | [How to measure] | [When] |
```

### 5.2 Define Validation Thresholds

```
Validation Threshold:
- Hypothesis CONFIRMED if [N] of [M] metrics hit target
- Hypothesis PARTIAL if [N] of [M] metrics show improvement
- Hypothesis REJECTED if <[N] metrics improve
```

## Exit Criteria

- [ ] Metrics defined with baselines and targets
- [ ] Measurement methods specified
- [ ] Timelines set for each metric
- [ ] Validation thresholds defined (confirmed/partial/rejected)
