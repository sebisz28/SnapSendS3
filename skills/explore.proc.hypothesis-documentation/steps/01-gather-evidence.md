# Step 1: Gather Evidence

## Objective

Collect evidence from discovery artifacts to support hypothesis creation.

## Entry Criteria

- [ ] Context baseline available
- [ ] Personas available
- [ ] Journey maps available
- [ ] Signal document available
- [ ] Slug confirmed

## Actions

### 1.1 Collect Evidence from Discovery Artifacts

```

From Context:
- Problem: [Reframed problem statement]
- Key insights: [2-3 insights from domain model]

From Personas:

- Pain points: [Top 3 pain points]

From Journey Maps:
- Current-state issues: [Key problems in journey]
- Opportunities: [Top opportunities identified]

From Signal:
- Why This Matters: [Signal's value proposition]

Synthesizing hypothesis...
```

## Exit Criteria

- [ ] Evidence collected from all available discovery artifacts
- [ ] Key insights, needs, pain points, and opportunities identified
- [ ] Evidence sources documented for traceability
