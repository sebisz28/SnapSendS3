# Step 8: Write Hypothesis Document

## Objective

Write the complete hypothesis document to `explore/explore-[slug]/hypothesis.md`.

## Entry Criteria

- [ ] Step 7 (Update Status) complete with STAKEHOLDER-VALIDATED status

## Actions

### 8.1 Write Document

Write complete hypothesis to `explore/explore-[slug]/hypothesis.md`.

**Use template**: `templates/hypothesis-template.md`

**Required sections**:
1. Hypothesis Statement
2. Evidence Base (table with sources and validation status)
3. Success Criteria (quantitative metrics and qualitative indicators)
4. Assumptions to Validate (critical and supporting)
5. Alternative Hypotheses
6. Validation Plan (phased)
7. Risks to Hypothesis
8. Stakeholder Validation (sessions and consensus)
9. Impact on Solution Design
10. Related Artifacts
11. Enrichment Log

### 8.2 Verify Document

Confirm the file contains all sections with no placeholder text remaining.

## Exit Criteria

- [ ] Document written to `explore/explore-[slug]/hypothesis.md`
- [ ] All sections present and populated
- [ ] No placeholder text remaining
