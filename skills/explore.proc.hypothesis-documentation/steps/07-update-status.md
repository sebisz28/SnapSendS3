# Step 7: Update Status

## Objective

Update hypothesis status after stakeholder validation.

## Entry Criteria

- [ ] Step 6 (Stakeholder Validation) complete with feedback

## Actions

### 7.1 Record Validation Result

```
Hypothesis Status Update

Status: DRAFT → STAKEHOLDER-VALIDATED
Validated By: [Stakeholder name/role]
```

### 7.2 Apply Revisions (if needed)

If stakeholders requested changes, update:
- Hypothesis statement
- Evidence base
- Assumptions list
- Success criteria

## Exit Criteria

- [ ] Status updated to STAKEHOLDER-VALIDATED (or revised and re-validated)
- [ ] Validation details recorded (who, when, notes)
- [ ] Any revisions applied
