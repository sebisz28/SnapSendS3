# Step 2: Draft System Overview and Architecture Approach

Begin the HLD by establishing the foundational framing — what the solution does, design goals, and the selected architecture pattern.

```
HLD: System Overview + Architecture Approach

## System Overview
[High-level description of what the solution does, how it operates, and design goals]
[Architectural boundary description — what is intentionally included and excluded]

Key Characteristics:
- [Characteristic 1]
- [Characteristic 2]
- [Characteristic 3]

## Architecture Approach
Pattern: [Selected pattern]
Rationale: [Why this pattern — reference feasibility, constraints, what flexibility is preserved]

Consistency check:
- [✓/✗] Overview matches boundary map scope
- [✓/✗] Architecture pattern matches approved sketch direction
- [✓/✗] Excluded systems explicitly stated (not silently omitted)

How would you like to proceed?
- Correct — proceed to component breakdown
- Adjust overview — tell me what to change in scope or framing
- Adjust pattern — the architecture approach should be different
```

**STOP**: Wait for architect to validate foundational framing.
