# Step 1: Identify Which Persona to Map

## Objective

Determine which persona to create a journey map for, the scope of the journey, and the typical timeframe.

## Entry Criteria

- [ ] Personas available (from Persona skill)
- [ ] Context baseline available
- [ ] Slug confirmed

## Actions

### 1.1 Ask for Journey Scope

```
Journey Mapping - Current State

Which persona should I create a journey map for?
- Reference persona ID (e.g., P1, P2)
- What is the scope of this journey? (e.g., "Patient scheduling appointment")
- What is the typical timeframe? (e.g., "2 weeks from awareness to completion")
```

**STOP**: Wait for human to specify persona and journey scope.

## Exit Criteria

- [ ] Persona identified by ID
- [ ] Journey scope defined
- [ ] Timeframe established
- [ ] Human has confirmed persona and scope
