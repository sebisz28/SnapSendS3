# Step 3: Map Current-State for Each Stage

## Objective

For each stage, document actions, thoughts, feelings, pain points, and touchpoints. Tag items as [VALIDATED] or [ASSUMPTION].

## Entry Criteria

- [ ] Step 2 (Define Stages) complete with stages confirmed

## Actions

### 3.1 Map Each Stage

For each stage, ask:

```
Stage [N]: [Stage Name] - Current State

For this stage, tell me:
1. Actions: What does [Persona] do?
2. Thoughts: What are they thinking?
3. Feelings: How do they feel? (frustrated, confident, confused, etc.)
4. Pain Points: What problems do they encounter?
5. Touchpoints: What channels/systems do they use?

I'll tag items as [VALIDATED] if you confirm them, or [ASSUMPTION] if I infer them.
```

**STOP**: Wait for human input for each stage.

### 3.2 Repeat for All Stages

Continue through all stages, collecting human input for each one.

## Exit Criteria

- [ ] All stages have current-state documented
- [ ] Actions, thoughts, feelings documented per stage
- [ ] Pain points identified per stage
- [ ] Touchpoints mapped per stage
- [ ] All items tagged [VALIDATED] or [ASSUMPTION]
