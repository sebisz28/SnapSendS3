# Step 2: Define Journey Stages

## Objective

Propose logical stages based on the journey scope. Typical pattern: Awareness → Research → Decision → Use → Support.

## Entry Criteria

- [ ] Step 1 (Identify Persona) complete with persona and scope confirmed

## Actions

### 2.1 Propose Journey Stages

```
Journey Stages Proposed

For [Journey scope], I propose these stages:
1. [Stage 1 name] - [Brief description]
2. [Stage 2 name] - [Brief description]
3. [Stage 3 name] - [Brief description]
4. [Stage 4 name] - [Brief description]
5. [Stage 5 name] - [Brief description]

Typical pattern: Awareness → Research → Decision → Use → Support

Confirm these stages or tell me how to adjust them.
```

**STOP**: Wait for human to confirm or adjust stages.

## Exit Criteria

- [ ] 4-7 journey stages defined
- [ ] Each stage has a name and brief description
- [ ] Human has confirmed stages
