# Step 5: Write Current-State Journey Map

## Objective

Write the current-state journey map to `explore/domain/journey-[slug].md`.

## Entry Criteria

- [ ] Step 4 (Identify Opportunities) complete with human validation

## Actions

### 5.1 Write Document

Write to `explore/domain/journey-[slug].md` using `templates/journey-template.md`.

**Required content**:
- Journey overview (scope, primary actor, timeframe)
- AGENT USAGE INSTRUCTIONS section
- Journey map table (current-state — future-state left empty for Part B)
- Narrative walkthrough
- Assumptions to validate
- Opportunities
- Validation summary

### 5.2 Verify Document

Confirm the file contains all required sections and uses consistent `journey_id` format.

## Exit Criteria

- [ ] Document written to `explore/domain/journey-[slug].md`
- [ ] Current-state complete for all stages
- [ ] Future-state columns empty (will be filled in Part B)
- [ ] AGENT USAGE INSTRUCTIONS section present
- [ ] Validation summary included
