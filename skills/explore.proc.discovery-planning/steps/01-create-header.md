# Step 1: Create Overview & Header

## Objective

Extract key information from the Signal to create the Explore Bundle header.

## Entry Criteria

- Signal document available
- Slug identified for file naming

## Actions

### 1.1 Extract Header Information

Create the bundle header from Signal:

```
Explore Bundle Header

Project: [Project name from Signal]
Slug: [slug]
Signal ID: [Signal ID]
Priority: [From Signal severity: 1-2=Low, 3=Medium, 4-5=High]
Explore Start: [Today's date]
Target Completion: [Estimated end date]
PM: [Product Manager name]
Status: PLANNING
```

## Exit Criteria

- [ ] Project name extracted from Signal
- [ ] Slug confirmed
- [ ] Priority mapped from Signal severity
- [ ] Timeline estimated
- [ ] Status set to PLANNING
