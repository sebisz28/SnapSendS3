# Step 12: Write Explore Bundle

## Objective

Write the complete Explore Bundle document to `explore/explore-[slug]/explore-bundle.md`.

## Entry Criteria

- [ ] Step 11 (Present for Approval) complete with human approval

## Actions

### 12.1 Write Bundle Document

Write complete bundle to `explore/explore-[slug]/explore-bundle.md` with all sections.

**Use template**: `templates/explore-bundle-template.md`

**Required sections**:
1. Overview (2-3 sentence summary)
2. Header (Status, Created, Timeline, Explore Type, Steering Team)
3. Signal Information (Title, Problem Statement, Tech Stack, Features, Requirements)
4. Solution Profile — Domains in Scope (table with In Scope and Description columns)
5. Planned Activities (phases with activity tables: Code, Activity, Owner, Dependencies, Output, What it closes)
6. Open Questions (categorized by type with resolution activities)
7. Active Assumptions (categorized by type: AS, AT, AO, AB with risk assessment)
8. Risks (table with Code, Risk, Impact, Likelihood, Mitigation)
9. Expected Outputs (comprehensive list with file paths)
10. Constraints (table by type: Budget, Timeline, Resources, Technical, Compliance, Operational)
11. Checkpoints (table with Milestone and Criteria)
12. Document History (version tracking)
13. Related Artifacts (links to Signal, Discovery Index, PRD)

### 12.2 Verify Document

Confirm the file contains all 13 sections with no placeholder text remaining.

## Exit Criteria

- [ ] Explore Bundle written to `explore/explore-[slug]/explore-bundle.md`
- [ ] All 13 sections populated
- [ ] Template structure followed
