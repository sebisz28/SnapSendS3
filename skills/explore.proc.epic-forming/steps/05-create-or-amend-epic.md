# Step 5: Create or Amend Epic

## Objective

Generate new epic shell or amend existing epic based on placement decisions, ensuring consistency with established patterns and template structure.

## Entry Criteria

- Placement decisions documented (Step 4 complete)
- Decision rationale established for each capability
- Ready to create or modify epic content

## Actions

### 5.1 Generate Epic Shell (New Epic)

For new epic creation:
- **Generate Epic ID**: Create appropriate epic identifier
- **Apply Template**: Use epic template to create shell structure
- **Populate Core Sections**: Fill in header, objective, scope based on capabilities
- **Establish Boundaries**: Define clear epic boundaries following established patterns

### 5.2 Amend Existing Epic

For existing epic amendment:
- **Load Existing Epic**: Access current epic content
- **Identify Amendment Areas**: Determine which sections need updates
- **Integrate New Capabilities**: Add new capabilities to appropriate sections
- **Maintain Coherence**: Ensure amended epic remains logically coherent

### 5.3 Populate Epic Content

Complete epic content with capability information:
- **Objective**: Clear statement of epic purpose and value
- **Scope & Boundaries**: What's included and excluded
- **Key Behaviors**: System capabilities the epic enables
- **Acceptance Criteria**: How success will be measured
- **Technical Approach**: High-level technical strategy

### 5.4 Document Implementation State

Include implementation state context:
- **Current State**: What capabilities already exist
- **Implementation Gaps**: What needs to be built or enhanced
- **Dependencies**: What other capabilities or systems are required
- **Iteration Context**: How epic fits into iteration planning

## Discussion Point (Governed Mode)

**STOP**: Present epic content for validation:
- "I've [created/amended] the epic based on placement decisions:"
- "Epic structure: [overview of epic content]"
- "Key capabilities included: [list of major capabilities]"
- "Implementation state context: [what exists vs what needs building]"
- "Does this epic content accurately represent the capability grouping?"

## Heuristic (Delegated Mode)

If in delegated mode:
- Generate epic shell using template for new epics
- Load and amend existing epics for amendments
- Populate epic content based on capability analysis
- Document implementation state automatically
- Proceed to Step 6 with completed epic content

## Exit Criteria

- [ ] Epic shell created or existing epic loaded
- [ ] Epic content populated with capability information
- [ ] Implementation state documented
- [ ] Epic structure follows template requirements
- [ ] Ready for epoch formation and boundary validation
