# Step 8: Index and Link

## Objective

Update epic index and establish cross-references, ensuring the epic is discoverable and properly linked to related artifacts.

## Entry Criteria

- Epic boundaries validated (Step 7 complete)
- Epic content finalized and coherent
- Ready for indexing and cross-referencing

## Actions

### 8.1 Update Epic Index

Add or update epic in the index:
- **Index Entry**: Add epic to `explore/epics/README.md`
- **Epic Description**: Provide concise description of epic purpose
- **Status Information**: Current epic status and implementation state
- **Cross-References**: Links to related epics and source materials

### 8.2 Establish Internal Links

Create cross-references within epic:
- **Source References**: Links back to source materials (PRDs, concepts)
- **Related Epics**: Links to related or dependent epics
- **Domain Models**: Links to relevant domain specifications
- **Decision Log**: Links to relevant architectural decisions

### 8.3 Validate Link Integrity

Ensure all links work correctly:
- **Internal Links**: Test all links within the epic document
- **External Links**: Verify links to source materials and other artifacts
- **Index Links**: Ensure epic index links work properly
- **Bidirectional Links**: Where applicable, ensure reciprocal links

### 8.4 Update Process References

Update any process documentation that references the epic:
- **Process Documentation**: Update processes that mention the epic
- **Iteration Planning**: Ensure iteration-management can find the epic
- **Epic-Forming**: Update epic-forming process references if needed
- **Project Documentation**: Update any project-level references

## Discussion Point (Governed Mode)

**STOP**: Present indexing and linking for validation:
- "I've updated the epic index and established cross-references:"
- "Index entry added: [epic description and status]"
- "Internal links created: [summary of cross-references]"
- "Link validation: [all links tested and working]"
- "Process references updated: [documentation that mentions the epic]"
- "Are the indexing and linking complete and correct?"

## Heuristic (Delegated Mode)

If in delegated mode:
- Update epic index automatically with standard format
- Create internal links based on capability analysis
- Validate all links using automated checking
- Update process references where applicable
- Proceed to completion with indexed and linked epic

## Exit Criteria

- [ ] Epic index updated with proper entry
- [ ] Internal cross-references established
- [ ] Link integrity validated
- [ ] Process references updated
- [ ] Epic discoverable and properly linked

## Process Complete

The epic-forming process is complete. The epic now:
- Represents logical grouping of system capabilities
- Maintains consistency with existing epic patterns
- Provides clean interface for iteration planning
- Is properly indexed and discoverable
- Is ready for iteration-management consumption
