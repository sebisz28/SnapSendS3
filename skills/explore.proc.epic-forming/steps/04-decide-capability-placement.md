# Step 4: Decide Capability Placement

## Objective

Apply decision framework to determine whether new capabilities require new epics or should amend existing ones, ensuring consistency with established patterns.

## Entry Criteria

- Existing epic patterns analyzed (Step 3 complete)
- New capabilities identified and documented
- Pattern logic and boundaries established

## Actions

### 4.1 Apply Pattern Matching

Test new capabilities against existing patterns:
- **Pattern Fit Test**: Does capability fit existing epic grouping logic?
- **Boundary Test**: Would adding capability maintain epic coherence?
- **Consistency Test**: Does placement follow established patterns?
- **Scope Test**: Is capability scope appropriate for existing epic?

### 4.2 Evaluate Placement Options

Assess each placement option systematically:
- **New Epic Option**: Benefits and drawbacks of creating new epic
- **Amend Existing Option**: Benefits and drawbacks of amending existing epic
- **Planning Efficiency**: Which option creates better iteration boundaries?
- **Stakeholder Clarity**: Which option makes more sense to stakeholders?

### 4.3 Apply Decision Framework

Use structured decision criteria:
- **Pattern Alignment**: Which option better follows established patterns?
- **Boundary Coherence**: Which option maintains epic boundary integrity?
- **Implementation Planning**: Which option supports better iteration planning?
- **Future Maintenance**: Which option is easier to maintain and evolve?

### 4.4 Document Placement Decisions

Record rationale for each decision:
- **Decision Outcome**: New epic vs amend existing epic
- **Decision Rationale**: Why this placement was chosen
- **Pattern Alignment**: How decision follows established patterns
- **Impact Assessment**: Effect on existing epics and iteration planning

## Discussion Point (Governed Mode)

**STOP**: Present placement decisions for validation:
- "I've applied the decision framework to the new capabilities:"
- "Pattern matching results: [summary of fits/mismatches]"
- "Placement decisions: [new epic vs amend existing for each capability]"
- "Decision rationale: [why each placement was chosen]"
- "Do these placement decisions align with your expectations?"

## Heuristic (Delegated Mode)

If in delegated mode:
- Apply pattern matching automatically using established logic
- Evaluate placement options using decision framework heuristics
- Choose placement that maximizes pattern consistency and planning efficiency
- Document placement decisions with automated rationale
- Proceed to Step 4 with documented placement decisions

## Exit Criteria

- [ ] Pattern matching applied to all new capabilities
- [ ] Placement options evaluated systematically
- [ ] Decision framework applied consistently
- [ ] Placement decisions documented with rationale
- [ ] Ready for epic creation or amendment
