# Step 10: Write Domain Analysis Document

## Objective

Write the complete domain analysis document to `explore/explore-[slug]/domain-analysis.md`.

## Entry Criteria

- [ ] Step 9 (Assumptions) complete with all assumptions prioritized

## Actions

### 10.1 Write Document

Write complete domain analysis to `explore/explore-[slug]/domain-analysis.md` with all sections.

**Use template**: `templates/domain-analysis-template.md`

**Required sections**:
1. Domain Glossary (Terms, definitions, synonyms, examples)
2. Domain Model (Entities, attributes, relationships, categories)
3. Entity Lifecycle States (States, transitions, rules per entity)
4. Domain Rules and Constraints (Business rules, constraints, invariants, validations)
5. User Roles and Responsibilities (Roles, permissions, tasks, permission matrix)
6. Current State (Processes, systems, pain points, what works well)
7. Domain Risks and Unknowns (Unknowns, assumptions, risks, edge cases)
8. Domain Model Summary (Core entities, relationships, implications)
9. Assumptions to Validate (Prioritized assumptions with validation plan)

### 10.2 Verify Document

Confirm the file contains all 9 sections with no placeholder text remaining.

## Exit Criteria

- [ ] Document written to `explore/explore-[slug]/domain-analysis.md`
- [ ] All 9 sections present and populated
- [ ] No placeholder text remaining
