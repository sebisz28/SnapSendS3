# Step 2: Signal Strengthen

**Objective**: Transform a low-confidence Signal Seed into a high-confidence, Route-Ready Signal by systematically completing the 7 completion criteria.

**Read ONLY this step file during execution. Do not load other steps until this step is complete.**

---

## Step Execution Rule

❌ Do not skip any of the 7 completion criteria during assessment.
❌ Do not leave importance or urgency scores without written rationale.
❌ Do not skip Explore Type recommendation.
❌ Do not proceed to routing without Medium or High confidence.

---

## Actions

### 1. Load the Signal

Ask the user which Signal to strengthen. Read the Signal file and verify State = "Active".

### 2. Assess Current Completion Status

Present a completion assessment table for all 7 criteria showing status (Complete/Partial/Missing) and specific gaps.

### 3. Complete Each Gap

Work through gaps in priority order. For each criteria area:

**Fundamentals**: Type, importance, source, duplicates
**Evidence & Context**: Evidence quality, context, historical patterns, claim tagging
**Framing & Meaning**: Scope, actors, constraints, expected outcomes
**Strategic Alignment**: North Star link, market context, regulatory, sponsor appetite
**Readiness & Feasibility**: Technical feasibility, data feasibility, organisational readiness, urgency, risk of inaction
**Prioritisation**: Importance score (1-5) with rationale, urgency score (1-5) with rationale, position (act now/next/nurture)

Urgency scale:
| Level | Label |
|-------|-------|
| 1 | No rush |
| 2 | Low |
| 3 | Some momentum |
| 4 | Strong demand |
| 5 | Pressing |
**Explore Type**: Score all three checklists (Fast Lane 5 items, Explore Readiness Check 4 items, Diverge/Converge 5 items), select highest-scoring type

### 4. Update the Signal Document

After completing each gap:
1. Update the Signal Seed document with new information
2. Ensure all new information is tagged (`[ASSUMPTION]`, `[OPINION]`, `[FACT]`)
3. Check the relevant completion checkboxes
4. Add Completion Notes entry

### 5. Reassess Completion Status

Present updated completion assessment showing before/after status for each criteria.

### 6. Generate Signal Summary

Append a **Signal Summary** section to the Signal document:

| Field | Content |
|-------|---------|
| Problem | One-sentence problem statement |
| Hypothesis | From "Why This Matters" — the core claim to validate |
| Confidence | Low / Medium / High |
| Key Evidence | Top 3 evidence points with tags |
| Critical Assumptions | Top 3 `[ASSUMPTION]`-tagged claims with highest risk-if-wrong |
| Actors | Key actors identified |
| Constraints | Key constraints identified |
| Importance / Urgency | Scores with one-line rationale each |
| Explore Type | Fast Lane / ERC / Diverge-Converge — with rationale |
| Sponsor | Name, appetite level |

### 7. Check Route-Readiness

Assess whether the Signal is ready for routing:
- Confidence: Medium or High
- Sponsor appetite: Confirmed
- All claims tagged
- Explore Type set

---

## Exit Criteria

- [ ] All 7 criteria assessed with clear status
- [ ] Gaps addressed with new information
- [ ] All new information tagged (`[ASSUMPTION]`, `[OPINION]`, `[FACT]`)
- [ ] Both importance and urgency scores include written rationale
- [ ] Signal Summary appended to the document
- [ ] Completion Notes updated with session entry
- [ ] Confidence level is Medium or High before routing

**Next step**: Step 3 (Signal Route) for routing decision, or repeat Step 2 (Signal Strengthen) if gaps remain.
