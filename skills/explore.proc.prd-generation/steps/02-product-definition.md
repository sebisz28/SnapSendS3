# Step 2: Generate Product Definition (Group 1)

## Objective

Generate Group 1 sections: Status, Links, Priority, Stakeholder Appetite, Problem Statement, Goals, Success Metrics, and Target Users.

## Entry Criteria

- [ ] Step 1 (Load Template) complete with all inputs verified

## Actions

### 2.1 Generate Group 1 Sections

Using the Signal-to-PRD bridge:

- **Status**: Draft
- **Links**: Signal, Hypothesis, Technical Feasibility (or HLD if available), Personas, Journey Map, Risk Register
- **Priority**: From Signal severity score (1–2 Low, 3 Medium, 4–5 High)
- **Stakeholder Appetite**: From Signal resonance score (1–2 Low, 3 Moderate, 4–5 High)
- **Problem Statement**: From Signal (stripped of tags, enriched by context reframe). 2–4 sentences describing the problem from the user's perspective.
- **Goals**: From "Why This Matters" + validated hypothesis outcomes. 3 measurable goals.
- **Success Metrics**: Table with Metric | Baseline | Target | Measurement Method | Timeline. All metrics must be measurable.
- **Target Users**: From Signal actors + persona need statements. Primary and secondary users.

## Exit Criteria

- [ ] All Group 1 sections generated
- [ ] Problem statement is user-focused (not solution-focused)
- [ ] Goals are measurable
- [ ] Success metrics have baselines and targets
- [ ] Target users linked to personas
