# Step 9: Assemble and Validate Design Sketch

Write the complete design sketch to `explore/hlds/[slug]-design-sketch.md`. Run the validation checklist.

**Validation checklist:**

- [ ] Service boundary proposed with justification
- [ ] All modules have non-overlapping responsibilities
- [ ] Runtime trigger identified with source
- [ ] Data model entities and authoritative sources mapped
- [ ] All events have direction, owner, and consumer
- [ ] All APIs have direction, purpose, and contract status
- [ ] Quality attribute constraints mapped for each top NFR from engagement brief
- [ ] Negative boundary statements present for every component (M4)
- [ ] Decision points presented as options with tradeoffs and NFR impact (not pre-resolved)
- [ ] Pattern library referenced for relevant decisions (if available)
- [ ] All architect selections recorded in decision log
- [ ] Open questions listed with impact and blocking status
- [ ] Every assumption tagged with evidence level (INFERRED / ASSUMED)
- [ ] Evaluation criteria calibrations logged
