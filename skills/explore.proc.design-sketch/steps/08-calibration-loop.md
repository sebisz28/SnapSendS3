# Step 8: Calibration Loop (on architect feedback)

When the architect provides feedback on any part of the sketch, classify the feedback BEFORE responding with revised content.

```
Feedback Classification

I've received your feedback. Before applying it, I'm classifying it:

Type: [A) Content Correction / B) Evaluation Function Reset / C) Context Injection]

[If Type A]:
Applying corrections to: [affected sections]
No change to evaluation criteria.

[If Type B]:
I'm reading this as a change in evaluation criteria, not just a content fix.
Previously I was optimizing for: [X]
Now I will optimize for: [Y]
This means I will now treat [specific items] differently:
- [Change 1]
- [Change 2]

Please confirm this interpretation before I proceed.

[If Type C]:
Integrating new context: [description]
Prior work affected: [sections that need re-evaluation]
Invalidated items: [items that are no longer valid]

How would you like to proceed?
- Correct classification — apply the feedback as classified
- Reclassify — this is actually a [different type] because [reason]
- Add more feedback — I have additional corrections
```

**STOP**: Wait for architect to confirm feedback classification. Repeat this step for each round of feedback until architect approves direction.
