# Step 5: Create Validation Summary

## Objective

Calculate validation priority for each persona and create summary table.

## Entry Criteria

- [ ] Step 4 (Present Validation) complete with all personas approved

## Actions

### 5.1 Calculate Validation Priority

**Validation Priority Calculation**:
- **High** = >50% of fields are assumptions (needs immediate validation)
- **Medium** = 25-50% of fields are assumptions (validate before major decisions)
- **Low** = <25% of fields are assumptions (well-validated, safe to use)
