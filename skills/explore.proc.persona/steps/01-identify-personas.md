# Step 1: Identify Personas

## Objective

Determine how many distinct user types to create personas for and get brief descriptions of each.

## Entry Criteria

- [ ] Context baseline available
- [ ] Signal document available (if exists)
- [ ] Slug confirmed

## Actions

### 1.1 Ask for Persona Count and Types

```
Persona Identification

Based on the Signal and context, I need to create user personas.

How many distinct user types should I create personas for?
- Provide the number and briefly describe each user type
- Example: "2 personas: 1) Healthcare provider, 2) Patient"
```

**STOP**: Wait for human to specify persona count and types.

## Exit Criteria

- [ ] Number of personas confirmed
- [ ] Each persona type briefly described
- [ ] Human has confirmed persona count and types
