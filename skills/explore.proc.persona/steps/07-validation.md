# Step 7: Validation

## Objective

Run a completeness check on the persona set document.

## Entry Criteria

- [ ] Step 6 (Write Document) complete
- [ ] Document exists at `explore/domain/personas-[slug].md`

## Actions

### 7.1 Run Completeness Check

Verify all required elements:

- [ ] All personas have unique IDs (P1, P2, etc.)
- [ ] Every field tagged with [VALIDATED] or [ASSUMPTION]
- [ ] Assumptions to Validate section present for each persona
- [ ] Brief Narrative written for each persona
- [ ] Validation Summary table complete
- [ ] Validation Priority calculated correctly
- [ ] File written to correct location

### 7.2 Present Validation Results

```
Persona Documentation Complete

File: explore/domain/personas-[slug].md
Personas: [N] created
Validation status:
  - P1: [X]% validated, [Y]% assumptions [Priority]
  - P2: [X]% validated, [Y]% assumptions [Priority]

Overall validation priority: [High/Medium/Low]

Ready for use in Journey Mapping and PRD Generation.
```

## Exit Criteria

- [ ] All completeness checks pass
- [ ] Validation results presented to human
- [ ] Document ready for downstream consumption
