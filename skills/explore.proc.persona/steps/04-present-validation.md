# Step 4: Present Personas for Validation

## Objective

Present each persona with validation status for human review and approval.

## Entry Criteria

- [ ] Step 3 (Create Documents) complete for all personas

## Actions

### 4.1 Present Each Persona

```
Persona [N]: [Name]

Demographics: [N] fields ([X] validated, [Y] assumptions)
Goals: [N] items ([X] validated, [Y] assumptions)
Pain Points: [N] items ([X] validated, [Y] assumptions)
Behaviors: [N] items ([X] validated, [Y] assumptions)

Validation Priority: [High/Medium/Low]
- High = >50% assumptions
- Medium = 25-50% assumptions
- Low = <25% assumptions

Top assumptions to validate:
1. [Assumption 1]
2. [Assumption 2]
3. [Assumption 3]

Review this persona:
- Approve (persona is accurate)
- Correct (tell me what to change)
- Add detail (tell me what's missing)
```

**STOP**: Wait for human validation of each persona.

### 4.2 Apply Corrections

If human requests changes, update persona and re-present.

## Exit Criteria

- [ ] All personas presented for review
- [ ] Human has approved each persona
- [ ] Corrections applied (if any)
