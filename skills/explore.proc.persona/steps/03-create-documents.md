# Step 3: Create Persona Documents

## Objective

Populate template sections for each persona with [VALIDATED] and [ASSUMPTION] tags, create assumptions list, and write brief narrative.

## Entry Criteria

- [ ] Step 2 (Gather Information) complete for all personas

## Actions

### 3.1 Populate Template Sections

For each persona, populate:
- Demographics table with [VALIDATED] or [ASSUMPTION] tags
- Goals & Motivations (3-5 items)
- Pain Points (3-5 items)
- Behaviors (2-4 items)
- Mental Models (2-3 items)
- Devices & Channels (primary, secondary, usage context)
- Values (2-3 items)

### 3.2 Tag Every Field

- `[VALIDATED]` = Human confirmed this information
- `[ASSUMPTION]` = Agent inferred from context or made educated guess

### 3.3 Create Assumptions to Validate Section

- List all [ASSUMPTION]-tagged items as checkboxes
- Prioritize by impact on design decisions

### 3.4 Write Brief Narrative

- 2-4 sentences in third person
- Use only [VALIDATED] data unless prefixed with "Assumed:"
- Example: "Maria is a 42-year-old nurse practitioner who manages 30+ patients daily. Assumed: She primarily uses mobile devices during patient rounds."

## Exit Criteria

- [ ] All persona sections populated
- [ ] Every field tagged [VALIDATED] or [ASSUMPTION]
- [ ] Assumptions to Validate section created per persona
- [ ] Brief narrative written per persona
