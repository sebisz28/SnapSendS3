# Step 1: Problem Statement

## Objective

Take the Signal's problem statement and create a comprehensive problem analysis with reframed problem, root cause, impact, and desired outcome.

## Entry Criteria

- Signal document available
- Slug identified for file naming

## Actions

### 1.1 Reframe Problem Statement

Create a comprehensive problem analysis:

```
Problem Statement

Reframed from Signal:
[2-3 paragraph problem statement that includes:
- What problem exists for whom
- Current situation and pain points
- Why existing solutions don't work
- What success looks like]

Root cause: [Single sentence identifying the fundamental issue]

Impact: [Specific consequences if problem remains unsolved - quantify where possible]

Desired outcome: [Specific, measurable outcome that solves the problem]

Confirm this problem statement or tell me how to adjust it.
```

**STOP**: Wait for human to confirm problem statement.

## Exit Criteria

- [ ] Problem statement reframed from Signal
- [ ] Root cause identified
- [ ] Impact documented with specifics
- [ ] Desired outcome defined (measurable)
- [ ] Human confirmed problem statement
