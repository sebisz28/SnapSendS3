# Step 6: Stakeholder Map & RACI

## Objective

Identify stakeholders with roles, influence, and engagement strategy, and create a comprehensive RACI matrix.

## Entry Criteria

- [ ] Step 5 (Technical Constraints) complete with confirmed constraints

## Actions

### 6.1 Identify Stakeholders

Document stakeholders:

```
Stakeholder Map & RACI

| Stakeholder | Organization | Role | Interest | Influence | Engagement Strategy |
|-------------|--------------|------|----------|-----------|---------------------|
| **[Name]** | [Organization] | [Title, Decision Authority] | [What they care about] | High/Medium/Low | [When/how to engage] |
| **[Name]** | [Organization] | [Title, Decision Authority] | [What they care about] | High/Medium/Low | [When/how to engage] |
```

### 6.2 Create RACI Matrix

```
### RACI Matrix

| Activity | [Stakeholder 1] | [Stakeholder 2] | [Stakeholder 3] | [Team] |
|----------|-----------------|-----------------|-----------------|--------|
| Signal approval | C | C | R | A |
| Explore Bundle approval | I | I | R | A |
| SP1: Context Capture | I | I | R/A | I |
| SP2: Stakeholder interviews | C | C | R | A |
| Hypothesis approval | C | C | R | A |
| SP3: Architecture (HLD) | C | I | R/A | I |
| SP5: PRD approval | A | A | R | C |
| Govern: Implementation | I | I | A | R |

Legend: R = Responsible, A = Accountable, C = Consulted, I = Informed
```

**STOP**: Wait for human to validate stakeholder map and RACI.

## Exit Criteria

- [ ] All stakeholders identified with organization, role, interest, influence
- [ ] Engagement strategy defined for each stakeholder
- [ ] RACI matrix created for all key activities
- [ ] Human validated stakeholder map and RACI
