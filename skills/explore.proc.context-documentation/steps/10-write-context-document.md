# Step 10: Write Context Document

## Objective

Write the complete context baseline document to `explore/explore-[slug]/context.md` consolidating all findings from Steps 1-9.

## Entry Criteria

- [ ] Steps 1-9 complete with all sections confirmed by human
- [ ] Slug confirmed for file naming

## Actions

### 10.1 Write Complete Document

Write complete context baseline to `explore/explore-[slug]/context.md` with all sections.

**Use template**: `templates/context-template.md`

**Required sections**:
1. Header (Signal ID, Phase, Created, Status)
2. Problem Statement (Reframed, Root cause, Impact, Desired outcome)
3. Scope & Boundaries (In Scope, Out of Scope, Boundary Conditions)
4. Domain Model (Core Entities table, Entity Relationships diagram)
5. System Map (Integration Architecture table, Data Flow Diagrams)
6. Technical Constraints (table with Status, Impact, Notes)
7. Stakeholder Map & RACI (Stakeholders table, RACI Matrix)
8. Governance Framework (Decision Authority, Approval Gates)
9. Assumptions Catalogue (with Owner and Closes In columns)
10. Gaps Catalogue (with Why It Matters and Question for Stakeholder)
11. Context Summary (One-Page Baseline)
12. Enrichment Log (initialized with SP1 completion entry)
13. Footer (Last Updated, Updated By)

### 10.2 Verify Document

Confirm the file:
- Contains all 13 sections
- Follows the template structure
- No placeholder text remains
- All human-confirmed content is included

## Exit Criteria

- [ ] Context document written to `explore/explore-[slug]/context.md`
- [ ] All 13 sections populated
- [ ] Template structure followed
- [ ] All findings from Steps 1-9 consolidated
